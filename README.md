# Run for the Bus 🚌

A fast-paced 2D arcade game built with Java and the LibGDX framework.

## 🎮 How to Play

### For Players (Windows)
1. Go to the **[Releases](../../releases)** section on the right side of this repository.
2. Download the latest `Run.for.the.Bus.zip
`.
3. Extract (unzip) the folder.
4. Double-click `Run for the Bus.exe` to play!

### Game Controls
* **Move Left / Right:** A / D
* **Move Up / Down:** S / W

---

## 🛠️ Built With

* **Language:** Java 21
* **Framework:** LibGDX (LWJGL3)
* **Build Tool:** Gradle
